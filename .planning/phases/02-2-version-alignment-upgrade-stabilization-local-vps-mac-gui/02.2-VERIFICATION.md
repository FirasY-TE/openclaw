## Health gates

Run after each surface upgrade (D-07, D-08).

**Local**

```bash
openclaw channels status --probe
```

**VPS** (default host/container from `.cursor/rules/vps-ssh-openclaw.mdc`; adjust alias/container only if your SSH rule differs)

```bash
ssh openclaw-vps "docker exec openclaw-ridl-openclaw-1 openclaw channels status --probe"
```

**In-container version spot-check**

```bash
ssh openclaw-vps "docker exec openclaw-ridl-openclaw-1 sh -lc 'which openclaw && openclaw -v'"
```

(Use `which` + `-v`: the Hostinger image may still ship an older tree under `/usr/local`; the **live** CLI after `deploy.sh --with-core` is under **`/data/.npm-global`**.)

## Rollback RUNBOOK

Version-only rollback (D-06). Replace `<prior>` placeholders with the semver, SHA, tarball, and Mac build you recorded at **Pre-upgrade (checkpoint 0)**.

1. **VPS — prior patched tarball** — Check out `~/openclaw-ops` at the commit that matched your prior `.openclaw-version` and patch set. Restore prior `vps/.openclaw-version` and `vps/patches/*` if needed. Run `./vps/build-patched-openclaw.sh` to rebuild the prior artifact, then `./vps/deploy.sh --with-core --restart`. Confirm `docker exec openclaw-ridl-openclaw-1 openclaw --version` matches expectation.
2. **Local npm** — Reinstall prior global CLI, e.g. `npm install -g openclaw@<prior>` (use the prior semver you documented).
3. **Mac GUI** — Reinstall or downgrade to the prior Sparkle/stable build you documented; restart gateway through the OpenClaw Mac app.

After rollback, re-run **Health gates** (local + VPS probes).

## Decommission greps (02.1)

Prove retired surfaces stay gone (D-08).

**Environment**

```bash
ssh openclaw-vps "docker exec openclaw-ridl-openclaw-1 env"
```

Effective container env must **not** contain `OPENCLAW_TRIAGE_DRAFT` (no `OPENCLAW_TRIAGE_DRAFT_*` vars).

**Draft-agent binary**

```bash
ssh openclaw-vps "docker exec openclaw-ridl-openclaw-1 test ! -f /data/openclaw-gws/bin/openclaw-gws-triage-draft-agent"
```

Expect exit code **0**. If your bind mount differs, document the equivalent path under `/data/openclaw-gws/bin` per `openclaw-ops` layout.
